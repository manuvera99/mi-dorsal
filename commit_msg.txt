## 3. Mapa visual con Leaflet + OpenStreetMap

### Dependencias
- `leaflet` + `react-leaflet` + `@types/leaflet` (instalado)

### Componentes
- `components/race-map.tsx`: el mapa en sí (con pines, popups, círculo de radio)
  - Pin central del usuario (rojo con borde blanco)
  - Pines de carreras (verde, gris si está fuera de rango)
  - Círculo del radio de filtrado (línea discontinua)
  - Popup con nombre, fecha, distancia, link
  - Tiles OpenStreetMap (gratis, sin API key)
- `components/race-map-wrapper.tsx`: wrapper con `next/dynamic({ ssr: false })`
  porque Leaflet toca `window` al importarse y rompe SSR

### Integración en /carreras
- Toggle "Lista | Mapa" en la cabecera
- Cuando se activa el mapa, las carreras SIN coordenadas se ocultan
  (no se pueden mostrar en un mapa)
- El mapa se centra en la ubicación del usuario si está activa
- Sin geolocalización, centra en el promedio de las carreras

### Privacidad
- Leaflet pide los tiles a OpenStreetMap (no a nosotros)
- La ubicación del usuario NO se envía a ningún servidor
- El cliente pide los tiles directamente al CDN de OSM

## Detalle técnico

- Error TS del build: `new Map<string, number>()` colisionaba con el
  componente `Map` de react-leaflet. Fix: `new globalThis.Map<...>()`.
- `formatDate` está en `@/lib/utils`, no en `@/lib/geo/distance` (corregido)
- Iconos custom con L.divIcon (los iconos default de Leaflet no cargan
  en Next.js por path resolution)
